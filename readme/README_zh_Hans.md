# my_claw

面向 Dify 的技能驱动型智能体插件：**技能渐进式披露** + **跨会话记忆** + **技能热插拔**。

my_claw 是 [mini_claw](https://github.com/lfenghx/mini_claw) v1.2.0（Apache-2.0）的现代化重构版，
经原作者授权二次开发发布，出处与致谢见 [NOTICE](../NOTICE)。

## 核心特性

- **技能包渐进式披露**：一个 zip（内含 SKILL.md 说明书与脚本）即可扩展一项能力；智能体只在任务命中时加载对应说明，上下文保持精简。技能清单采用强类型校验，可用性判定从“启发式猜测”升级为“确定性结论”。
- **整轮流式 + 推理双通道**：一次模型调用是不可分割的轮次——含工具调用的中间轮不对外发布任何模型文本，最终轮发布完整且标签配对的正文；推理内容优先消费平台提供的 `reasoning_content` 独立字段，旧平台自动回退 `<think>` 标签解析。彻底告别“正文被思考折叠区吞掉”。
- **跨会话记忆与人格**：四文档人格模型（身份/用户画像/风格规则/托管记忆）+ 每日对话摘要，全部模块化并可单测。
- **真实工作的技能弹药库**：文档生成（docx/xlsx/svg/ics）、群消息推送（飞书 webhook）等零依赖技能包。
- **安全优先的执行**：命令白名单、路径逃逸防护、SSRF 防护抓取、zip-slip 防护、敏感操作审批。
- **平台无关内核**：智能体内核零 SDK 依赖、单元测试全覆盖；Dify 只是一个适配层。

## 安装

- **市场安装**：在 Dify 插件市场搜索 my_claw（上架中）。
- **本地安装**：构建/下载 `my_claw.difypkg`，在 Dify「插件 → 安装插件 → 本地插件文件」上传。

## 快速上手

1. 新建或打开 Chatflow，添加工具节点并选择 my_claw；
2. 为节点配置工作区内任意模型；
3. 将用户输入（及可选文件列表）接入节点，节点 `text`/`files` 输出接入回复节点；
4. 在应用里试一试：

   ```text
   查看技能
   帮我算一笔租赁：本金500万，年利率6%，36期等额本息
   把结果发到项目群
   ```

技能管理命令也直接接入同一个 my_claw 节点：`查看技能` / 上传 zip + `新增技能` / `删除技能2` / `下载技能2` / `依赖安装`。my_claw 会先识别明确的管理意图，再转给内置 skill manager；普通任务即使含有“技能”字样也会继续执行主 agent 循环。不要在 Chatflow 中另建“包含技能”条件分支，否则会绕过该路由边界。

## 开发

```bash
pip install -r requirements.txt pytest
pytest tests/ -q           # 内核单元测试（无需 Dify）
python scripts/package.py  # 打包 my_claw.difypkg
```
